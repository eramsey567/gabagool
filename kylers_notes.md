# Kyler's Notes: What Makes a Good Idea

The niche should push hard on what AI and code do well, not on graphics.

## Checklist for a good idea

1. **Code can check the quality.** Every puzzle can be proven correct: one solution, no answer-key mistakes, difficulty graded properly.
2. **AI supplies the words.** Clues, scenarios, themed vocabulary and variety are what make the book better, and AI can produce them in volume.
3. **Few or no facts to check.** Fictional or self-contained content, like logic puzzles, is safest. Trivia and quotes work, but each fact needs checking.
4. **No reliance on graphics.** The inside is type and grids. Only the cover needs real design, and a person makes it.
5. **Hard for competitors to make by hand.** If one person with a template can produce it in an afternoon, the category is already crowded. Our edge is in formats that are tedious or hard to get right manually.
6. **A specific buyer with a need you can name.** For example, "older solvers who want gentle logic puzzles in large print", not just "puzzle fans".
7. **Buyers can find it by searching.** There's a phrase people type into Amazon, and existing books show demand but have weak reviews or complaints.
8. **The quality shows on the page.** A buyer flipping through "Look Inside" can see it's better, through legibility, variety and polish.

**In one line:** a puzzle format that's hard to make by hand, where code guarantees correctness and AI supplies variety, sold to a specific buyer who already searches for it.

## Ideas so far

| Rank | Idea | Fit |
|---|---|---|
| 1 | **Logic grid puzzles** ("Einstein puzzles"), large print, gentle to hard | Meets all 8. Code proves one solution and grades difficulty; AI writes a different fictional scenario for each puzzle |
| 2 | **Clue-based / trivia puzzles** (memory care reminiscence, field-specific like nurses or gardeners) | Strong content, but fails #3: every fact needs checking |
| 3 | **Cryptograms of famous quotes** | Code encrypts, AI sorts quotes by theme. Quote attributions need checking |
| 4 | **Plain word search and sudoku** | Code keeps them error-free, but that edge is hard to show in a crowded category |
